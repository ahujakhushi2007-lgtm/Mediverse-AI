# MediVerse (react-router-dom removed)

This is a simplified version of the MediVerse project using only:
JSX, Functional Components, Props, State (useState), useEffect,
rendering lists, and conditional rendering.

Navigation is handled with plain React state in `src/App.jsx`
(a `page` + `params` state, updated via a `navigate()` function)
instead of react-router-dom.

## Run locally
npm install
npm run dev
